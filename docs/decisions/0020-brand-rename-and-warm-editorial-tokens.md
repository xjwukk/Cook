# 0020 品牌更名「料理手帐」与手账插画 logo

- 状态：已采纳
- 日期：2026-11-11
- 关联：[0019 Web 视觉方向：温暖编辑式](./0019-warm-editorial-web-visual-direction.md)、[0004 iOS App 命名为「云食册」](./0004-ios-app-name.md)、[0016 原生 Android 与 Capacitor 外壳退役](./0016-native-android-and-capacitor-retirement.md)、[设计系统与契约](../dev/design-system.md)

## 背景

项目此前对外叫「食用手册」（Cook），品牌资产是 0005 定的蓝色「蒸汽成云」应用图标。0019 把 Web 视觉方向定为温暖编辑式后，这套蓝色图标与新的暖纸面 + 陶土橙调性冲突；同时「食用手册」这个名字里的「手册」偏工具感，与新的「一本摊开的食谱册」隐喻不符。

三端现状不同：Web 是 Nuxt + Ionic，样式自成一套；iOS 是 SwiftUI 原生应用，主屏名按 0004 叫「云食册」，App Store 名称是「云食册 - 食用手册」；Android 尚无工程（0016 决定启动阶段再核对命名与包身份）。

维护者提供了新的手账插画 logo（仓库根目录 `logo.png`）：米黄纸面手账本 + 一盘米饭、溏心蛋、青菜与叉子，配色为暖白、粉色书脊与薄荷绿点缀。

## 方案对比

| 方案                                      | 取舍                                                                                       |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ |
| **改名「料理手帐」+ 换插画 logo**（采纳） | 「手帐」同时指手写笔记与食谱册，呼应温暖编辑式；插画本身即暖纸面配色，与 0019 令牌天然一致 |
| 只换 logo 不改名                          | 名字与「一本摊开的食谱册」的视觉叙事割裂；且搜索与老用户的既有认知仍在「食用手册」上       |
| 保留蓝色「蒸汽成云」                      | 与暖纸面、陶土橙并存会形成两个品牌体系；0005 的图标方向已被新插画取代                      |
| iOS 主屏名一并改成「料理手帐」            | 0004 明确区分了 iOS 与网页的名字，用来区分免费网页版与付费原生版；一并改名会丢掉这层区分   |

## 决定

- **名称**：Web、PWA 与未来的 Android 叫「料理手帐」；英文名 Cook 与开源仓库名不变。iOS 主屏名仍是「云食册」（0004 的区分保留），App Store 名称随之改为「云食册 - 料理手帐」。iOS 内引用网页版的地方改称「料理手帐网页版」。
- **logo**：`logo.png` 是唯一设计源。新增 `scripts/generate-brand-icons.mjs` 从它派生各端尺寸：Web 侧栏品牌图、favicon、apple-touch-icon、PWA 图标、iOS AppIcon 的 1024 兜底位图，以及 iOS 26+ Icon Composer 的分层图标（纯纸色填充 + 手账本图层）。换 logo 只需重跑该脚本。
- **iOS 视觉**：新增 `AccentColor.colorset`（浅色 `#C4552D`、暗色 `#E08A5F`）作为全局 accent 色，与 Web 的 `--c-brand` 对齐；`LaunchBackground.colorset` 换成暖纸色（浅色 `#FBF7F0`、暗色 `#17130F`）。iOS 其余界面继续用系统色，不为了跟 Web 像素一致而放弃平台惯例。
- **Android**：不建空工程（0016），但把名称、图标来源、语义色令牌与三端断点写进 [Android 分阶段计划](../dev/android-roadmap.md)，实现时直接沿用。
- **旧签名资产**：`AppIcon.icon/Assets/` 下的 `pot-cloud.svg`、`ladle.svg` 带 C2PA 签名，已不再被 `icon.json` 引用；保留在仓库里不删除，是否清理等维护者决定。
- Web 端主题色（`theme-color`）、启动占位页的配色一并改为暖纸色，避免加载前后闪一次冷灰。

## 影响

- 旧名「食用手册」在 `docs/decisions/0004` 的背景段落、`HelpAbout` 的历史沿革（故原名「隔离食用手册」）中作为历史记录保留，不是当前产品名。
- 站点地图、`llms.txt`、SEO 标题与描述、关于页与用户协议的产品名同步更新；iOS 原生 App 的商店条目名称需要在下一次发布时由维护者同步。
- iOS 的图标与 accent 改动无法在 Windows 上构建验证，需要在 macOS 上跑一次 `xcodegen generate` 与真机/模拟器截图核对。
- 品牌图标的生成脚本引入 `sharp` 依赖（已在根 `devDependencies` 中），不进入运行时产物。
